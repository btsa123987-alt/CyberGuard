# CyberGuard visual design decisions

Design process uses the public [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) skill by Next Level Builder (MIT, copyright 2024 Next Level Builder). No skill runtime or third-party assets are bundled in CyberGuard.

The project followed its `SKILL.md` priority list and the original catalog entries:
- `ui-reasoning.csv` → **Cybersecurity Platform**: high-contrast dark operations UI, threat visualizations, technical yet readable text.
- `charts.csv` → temporal data: labeled line chart; part-to-whole: donut plus textual counts; comparative observations: bar chart with category labels.
- `quick-reference.md` → keyboard focus and form feedback, mobile reflow, meaningful empty states, reduced motion, accessible legends and contrast.

**User-directed adaptation:** the skill's default Cybersecurity palette is matrix green. CyberGuard uses charcoal + violet with red/amber/mint severity as requested by the visual reference, rather than incorrectly claiming that palette was generated by the skill. The application displays *only actual scans made in this browser tab* — no invented live-threat events.

## Design tokens

- Canvas: `#101015`; chrome: `#14141a`; panel: `#1b1a23`; border: `#383240`
- Primary text: `#f5f2fc`; muted: `#b6afc5`; accent: `#b989ff`
- Severity: high `#ff7582`, elevated `#f8c86c`, low `#69d5a7`
- Compact, responsive dashboard with `44px` minimum interactive controls, visible focus indication, meaningful empty states, semantic headings and data table fallback for charts.

## Architecture

- `/` scanner (URL + QR) · `/dashboard` session results
- JS SVG charts with no CDN dependencies
- URL detection remains deterministic and offline; no trained model confidence is displayed
- No images or code copied from the screenshot or skill's examples
