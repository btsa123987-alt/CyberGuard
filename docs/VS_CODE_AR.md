# تشغيل CyberGuard في VS Code على Windows

> هذا الدليل لحساب GitHub: `oull1i`. التطبيق **محلي فقط** ولا يستقبل اتصالات من الإنترنت افتراضيًا.

## قبل البداية

- ثبّتي **Visual Studio Code** و**Python 3.11 أو أحدث** (المشروع اختُبر على 3.11 و3.12 و3.13).
- يفضّل وجود **Git for Windows** حتى تستنسخي المشروع من GitHub.
- يلزم اتصال إنترنت **في المرة الأولى** لتنزيل المكتبات؛ فحص الروابط بعد ذلك لا يفتح الروابط ولا يرسلها إلى موقع خارجي.
- افتحي المشروع من مصدر تثقين فيه؛ ملف إعداد VS Code سيشغّل أمر تثبيت المكتبات محليًا، ولن يحدث هذا قبل تشغيله داخل VS Code.

## 1. افتحي المشروع من GitHub

1. افتحي VS Code.
2. من القائمة **View → Command Palette** (أو `Ctrl+Shift+P`).
3. اكتبي **Git: Clone**.
4. الصقي رابط المستودع:
   `https://github.com/oull1i/CyberGuard.git`
5. اختاري مجلدًا مناسبًا على جهازك، ثم اضغطي **Open**.
6. إذا سأل VS Code عن الثقة بالمجلد **Trust**, اقبلي فقط إذا تأكدت أنه مستودعك.

> إذا لم يظهر أمر Git: Clone، ثبّتي Git for Windows ثم أعيدي تشغيل VS Code، أو حمّلي ملف ZIP من GitHub وافتحي المجلد المستخرج عبر **File → Open Folder**.

## 2. شغّلي Flask بضغطة F5

1. إذا طلب VS Code تثبيت إضافات **Python** و**Python Debugger** فوافقي.
2. افتحي **Run and Debug** من الشريط الجانبي (`Ctrl+Shift+D`).
3. اختاري **CyberGuard: Run Flask (Windows)**.
4. اضغطي **F5** أو زر التشغيل الأخضر.
5. أول تشغيل ينشئ مجلدًا محليًا `.venv` ويثبّت مكتبات `requirements.txt` تلقائيًا. قد يأخذ ذلك بعض الوقت بحسب الاتصال.
6. بعد ظهور `Running on http://127.0.0.1:5000` افتحي **http://127.0.0.1:5000** في المتصفح.

> لإيقاف الخادم، اضغطي مربع **Stop** الأحمر في شريط التصحيح. فتح الصفحة وحده لا يشغّل الخادم.

## 3. اختبارات المشروع (اختياري)

من **Terminal → Run Task** اختاري **CyberGuard: Run tests**. ستُثبّت تبعيات الاختبار ثم تعمل اختبارات `pytest`. وجود Flask ضمن المشروع لا يعني أن الموقع يعمل إلا عندما يكون الخادم قيد التشغيل.

## في حال ظهور خطأ

| العرض | السبب الشائع | الحل |
| --- | --- | --- |
| `py: command not found` | برنامج تشغيل Python غير متاح على Windows | شغّلي `python scripts/vscode_setup.py` من Terminal، أو ثبّتي Python مع مشغل `py` |
| `No module named flask` | استخدمت Python خارج `.venv` أو لم يكتمل التثبيت | شغّلي مهمة **CyberGuard: Set up environment** من **Terminal → Run Task** |
| `No module named cv2` | لم تُثبت تبعيات قراءة الصور | أعيدي مهمة التجهيز وتأكدي من اتصال الإنترنت |
| `Address already in use` | المنفذ 5000 مستخدم | أوقفي الخادم القديم؛ أو غيّري `PORT` في `.vscode/launch.json` |
| لا توجد إعدادات F5 | لم تفتحي جذر المستودع أو نسختِ نسخة قديمة | افتحي المجلد الذي يحتوي `app.py` و `.vscode`؛ ثم نفذي Git Pull |
| `Python interpreter invalid` | البيئة لم تُنشأ أو اختير مفسر مختلف | استخدمي **Python: Select Interpreter** وحددي `.venv\\Scripts\\python.exe` بعد التجهيز |

## دون استخدام تصحيح VS Code

يمكنك تشغيل الأوامر التالية في PowerShell داخل مجلد المشروع:

```powershell
py -3 scripts/vscode_setup.py
.\\.venv\\Scripts\\python.exe app.py
```

ثم افتحي `http://127.0.0.1:5000`.

**الخصوصية والأمان:** لا تشاركي رموز GitHub أو كلمات المرور داخل الكود، ولا تفعّلي `debug=True` على خادم متاح للعامة. أداة تحليل الروابط محلية ولا تؤكد أن الرابط منخفض الدرجة آمن بشكل قطعي.
