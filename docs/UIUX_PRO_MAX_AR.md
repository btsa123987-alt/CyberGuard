# استخدام UI/UX Pro Max مع CyberGuard

> **مهم:** الأداة هنا ليست إضافة Flask ولا ميزة تعمل داخل صفحة الفحص؛ هي *مهارة تصميم* تساعد مساعدات البرمجة على اختيار أنماط الواجهات والألوان وUX. تعديل الواجهة v3 نفّذناه ضمن المشروع مباشرة، ولا يعتمد تشغيل CyberGuard على تثبيت الأداة.

**المصدر الرسمي:** https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

**الترخيص:** MIT (متاح في مستودع المصدر). أضفنا اسم المصدر والاعتراف بالمساهمة، ولم ننسخ قواعد البيانات الخارجية الكبيرة إلى CyberGuard.

## ماذا دُمج بالفعل؟

1. واجهة عربية أساسية RTL، مع تبديل اختياري للإنجليزية.
2. أسلوب Cyber Neon هادئ واحترافي، مع توكنات ألوان متسقة، مقياس خطورة، ورادار SVG.
3. تحليلات SVG وحلقة توزيع مخاطر وقيم ملخصة **من نتائج الفحص الحقيقية** داخل الجلسة.
4. مراعاة لوحة المفاتيح، التباين، والواجهات المصغرة وتقليل الحركة.
5. معيار تصميم دائم في `design-system/cyberguard/MASTER.md` وإرشادات Copilot في `.github/copilot-instructions.md`.

## تثبيت مهارة UI/UX Pro Max الأصلية في VS Code (اختياري)

يحتاج هذا القسم إلى **Node.js + npm** ووجود امتداد GitHub Copilot في VS Code عند استخدامه. لا تحتاجين تثبيت الأداة لتشغيل Flask.

افتحي Terminal داخل **جذر مجلد CyberGuard** (المجلد الذي يحتوي `app.py`) ثم شغّلي:

```powershell
npx ui-ux-pro-max-cli init --ai copilot
```

الأمر المذكور هو مسار التثبيت الذي توصي به وثائق **nextlevelbuilder** لدعم GitHub Copilot. سيقوم بتحميل الحزمة من npm؛ راجعي المصدر والترخيص قبل تشغيل أي كود خارجي. إذا سأل `npx` عن تثبيت حزمة وافقي فقط إذا كنتِ تثقين بالمصدر.

إذا كنتِ تستخدمين **Codex CLI** بدل GitHub Copilot، استبدلي `copilot` بـ `codex`:

```powershell
npx ui-ux-pro-max-cli init --ai codex
```

بعد التثبيت، شغّلي مساعد البرمجة المناسب واطلبي منه قراءة المهارة وقواعد التصميم الخاصة بـCyberGuard قبل تعديل الواجهة. المساعد نفسه يحتاج دعم قراءة skills؛ مجرد تثبيت الحزمة لا يغيّر شكل الموقع تلقائيًا.

## طلب جاهز لمساعد VS Code

> حسّن واجهة CyberGuard باستخدام UI/UX Pro Max. اقرأ `design-system/cyberguard/MASTER.md` أولًا، ثم طبّق تصميمًا عربيًا RTL Cyber Neon مع رسومات أمنية حقيقية قابلة للتفسير، ووضع إنجليزي متكامل، دون تغيير Flask API أو إرسال الروابط إلى الإنترنت. اختبر إمكانية الوصول والجوال قبل النشر.

## إعادة تشغيل CyberGuard بعد التحديث

على جهاز Windows، افتحي المجلد المحدّث في VS Code واختاري `CyberGuard: Run Flask (Windows)` ثم `F5`. بعد ظهور الرسالة افتحي:

http://127.0.0.1:5000

إذا كانت الواجهة القديمة ما زالت تظهر، تأكدي أنك حصلت على أحدث نسخة من GitHub وأعيدي تحميل الصفحة بـ `Ctrl + Shift + R`.
